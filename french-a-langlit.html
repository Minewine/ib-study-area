DP1 routine: one real francophone non-literary text per week (editorial, ad, speech, cartoon) analysed in French. Keep a running bank of global issues for the IO.

Individual oral — build the bank early (feeds DP2, pays weekly)

A global issue is not a topic label (« les inégalités ») — it is a debatable statement, broad enough to be called global, narrow enough to anchor in the extract and one literary work. The weekly routine: every text analysed for P1 practice gets one candidate issue line in the bank below; an issue only becomes usable once it has (a) a non-literary text and (b) a literary work with a specific passage. Ten minutes a week now makes the IO choice calm in DP2.

Marking vocabulary for P1 and the IO: the Cards page has a French terminology deck (procédés stylistiques, registres, argumentation) — run it before each written analysis.
