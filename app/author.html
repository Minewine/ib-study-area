5 · Backup & move between devices

Logged in, everything syncs on its own. The backup file holds all progress and uploads in this browser (quiz, cards, missed questions, checklists, lists, notes). Restoring shows what's in the file and merges it in by default, after saving a safety copy; older exports from this page still work.

Tip: to make an uploaded bank permanent for all devices, save its JSON into library/questions/ (or library/flashcards/) and add one line to the matching manifest.json — see docs/AUTHORING.md.
