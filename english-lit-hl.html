How the components feed each other

One discipline makes all four assessment components work: keeping quote banks and theme maps per studied work. P2 compares across works, the HL Essay goes deep on one work, the IO links two works through a global issue, and P1 rewards the analytical vocabulary practised on unseen texts. The French A hub's IO global-issue bank should share entries with this one — the same issues often serve both languages.

Vocabulary for that analysis: the Cards page has a literary-terms deck (term → definition + the effect a writer is buying with it) — drill it alongside the weekly P1 passage.
